Plex is the core plugin for free-OP and anarchy servers, also called freedom servers. It changes how the entire server
works, so that the server fits a world where every player has broad powers. Plex is an alternative to
[TotalFreedomMod](https://github.com/TotalFreedom/TotalFreedomMod). It keeps the core features that make a freedom server
work, and it adds features that a freedom server needs to run well.

Plex uses permission-based freedom. It works with any Vault-compatible permissions plugin, such as LuckPerms. You can
drop the traditional rank system and control what each player can do with permission nodes. This gives you exact control
over the server.

Plex stores player data in SQLite, MariaDB, or PostgreSQL, so you can start small and scale up as your community grows.
If you run more than one server, Plex can use Redis to share admin chat and ban updates between them.

Plex is customizable. You can change almost every message and the chat format to match your server. You can also create
as many custom worlds as you need.

Plex has a module system. You can add or remove modules to fit your server, so the plugin stays as light or as
full-featured as you want.
